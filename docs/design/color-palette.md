# 15. 色板

来源：设计稿「Coforge UI 设计规范 · Color」（持续更新）。设计稿与本文冲突时以设计稿为准，并同步改本文。颜色在代码里只走语义 token，不写十六进制（见[第 11 节](color-status-typography.md)）；本节的色值是设计稿给出的目标值，用来核对 token。

## 与代码对照（亮色模式）

对齐在 `apps/web/src/styles/coforge-theme.css` 的 `:root:not(.dark-mode)` 里，用语义 token 覆盖，不动 `theme.css` 的色阶。设计稿没有暗色值，暗色沿用 Untitled。

| 在线 / 掉线 | `#1BB618` / `#AFBCCB` | `--color-online` / `--color-offline` | 一致 |

## 未读标记

色板页把"未读消息"画成红色，但会话列表的设计稿（私聊、群聊行）把未读数字角标画成品牌紫底白字，以更具体的列表稿为准：未读数字角标和未读小圆点都用 `bg-brand-solid`（白字对比度约 6.9:1，达标）。全站只有 `components/ui/unread-marker.tsx` 的 `UnreadBadge`、`UnreadDot` 两个出处（侧栏、会话列表、线程摘要、记录列表）。未读会话行的底色和消息流里的未读分割线也用品牌紫（见[第 11 节](color-status-typography.md)）。

## 红色、绿色和文字灰没有采用（2026-10-09）

设计稿的红 `#F15341`、绿 `#1BB618` 会被当作文字色，或作为实心底色配白字，而它们不满足 WCAG AA 对小字的 4.5:1：白字配 `#F15341` 约 3.5:1，`#F15341` 红字在白底上同样约 3.5:1，绿字 `#1BB618` 在白底上约 2.7:1。代码因此保留 Untitled 的标准红（`#E7000B`，白字约 4.8:1）和绿，只对齐不涉及文字的颜色：在线点 `--color-online` 本来就是 `#1BB618`。

设计稿的文字灰 `#777D8D` 在白底上约 4.1:1，同样低于 4.5:1，也不采用，`text-tertiary`、`text-quaternary` 保留 Untitled 的标准灰。
