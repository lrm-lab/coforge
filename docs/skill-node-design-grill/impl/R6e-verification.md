## 5. 结论与策略读数

1. **修的是尺子，不是通道**：同一候选池，只换合并口径，A12 从 15.2% 变 59.0%@10（+43.8 个百分点），离 T 只差 2.8 个百分点。R6d 那组「36.4%」的数字是在坏尺子上量的，**不能再用来描述通道能力**（R6d 验证记录里「B≈A4 打平」的结论在新尺子下修正为：投影比同座位 atom **低 2–3 个百分点**）。
2. **座位行为恢复正常**：4→12 在 ranked 下 +3.0（atom）／+2.3（投影）个百分点；旧口径是 −21／−20.6。
3. **RRF 不如 max-BM25**：低 4.6–6.9 个百分点 → 主口径取 max-BM25，RRF 只作交叉检查。
4. **fallback 形状上投影通道仍只是 atom 通道的近似复制**（低 2–3 个百分点），所以 #126「生产不接 resolver」的裁定不变——接了也只是更接近 atom 通道，而这个通道自己不缺候选。
5. **⚠ 战略读数（重要）**：**L1 这个指标已经被词法方法打到接近天花板**——atom 通道 59.0%、T 61.8%，两者只差 2.8 个百分点。剩下 38% 的题不是「排序没排好」，而是「词法根本不匹配」。因此：(a) 任何**零 LLM 的结构代理**（摘要截短、同实体桥等，都是词法手段）在这个指标上**测不出结构价值**，我原打算的 R6f「结构代理臂」**据此取消**（自证无效的测量不值得花一浪）；(b) 结构（模型写的摘要／claim）若要显价值，必须换**不被词法饱和**的指标或换场景——见下。
