- **Q71：B。**HypothesisBridge 创建后成为全局长期可遍历的 hypothesis edge，所有任务均可在探索时沿它多跳；它仍不能作为 EvidenceBridge 或因果证明。

- **Q74：A。**Verified 与 provisional 使用独立召回配额和排序通道，再带状态标签混合输出；hypothesis citation 只影响 provisional 通道内部排名。
