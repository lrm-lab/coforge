❓ Q47 - 假想分支的变质是否由证据基础失效驱动，而非按时钟过期，并以有效置信度与 supersede revision 表达？

下列事件仅在影响该 manifest 所覆盖的簇、边或证据时触发变质评估：新同簇真实轨迹 commit、相关 cluster 成员或 verified edge 的增删/替代、可比预测误差跨越 surprise 阈值、原始证据被 redaction/tombstone/ACL 政策变更。普通时钟不直接令其过期；最多可排队“复核”，但不能单凭时间降低可信度。

text

needs_revalidation    freshness_factor = 0.5
invalidated           freshness_factor = 0.0

effective_confidence =
  calibrated_confidence × freshness_factor


needs_revalidation 表示分布或证据基础出现实质变化但尚未证明原假设错误；invalidated 表示关键前提失效或已有高质量、可比的反证。任何调整均创建不可变新 revision，使用 supersedes_revision_id、invalidation_event_refs[]、新旧 manifest diff 与判定版本连接；旧分支保留为历史证据、禁止静默删除或原地改写。只有 fresh 且存在可用校准置信度的分支可作为稳定排序信号。

➡️ 推荐答案：确认。用证据基础 manifest 的变化而非 TTL 管理变质；时间仅可触发复核队列。采用 calibrated_confidence × freshness_factor，并以 fresh / needs_revalidation / invalidated = 1.0 / 0.5 / 0.0 作为确定性状态；所有改变以 superseding revision 审计化。

❓ Q48 - 是否以可恢复 diagnosis dossier 而非持久化 agent，承载增量再诊断、漂移审计与防自证回声？

3. 其所在 cluster 至少有 3 条来自至少 2 个独立 session 的真实、可比较证据；
4. 最近 3 次相关证据变化事件均未造成该 branch 的语义结论翻转；
5. 通过独立 imaginer 的双样本检查，或显式带有未解决的 disagreement 降权标记；
6. 来源和所有待展开证据在本次 replay 时仍通过 ACL、Q30 七步 eligibility 与 Q43 的路径限制。

资格分数可按“有效校准置信度 × 稳定性 × 同簇真实证据量 × 预期 replay 信息价值”排序，以决定已批准 replay 预算投入到哪些**既有、合规的 skill revision**。这不改变 Q43：replay 的候选 skill 仍只能来自语义验证通过、真实且有正向效用 branch 所使用的 revision；想象分支只能影响“优先验证哪一个既有候选”，不能单独引入新 skill、绕过真实效用门槛或申请更多分支预算。

验证状态应明确为双通道：同簇真实轨迹与 forecast contract 相符，**或** 配对 replay 相比无-guidance 基线有可观测改善，任一可使 imagined branch 成为 validated；两者都没有时仍是 hypothesis。真实吻合优先提高跨树排序，replay 验证优先提高实验/指导证据；任一通道均不等于 executable skill 晋升，后者仍须 evaluator 审批。

➡️ 推荐答案：确认。稳定性是证据事件下的可审计资格，不是静态年龄分；采用上述六项门槛与 ≥0.70 有效置信度。稳定想象只用于 replay 投资排序和假设验证，不能违反 Q43 的真实正向 branch skill 来源限制；验证允许“同簇真实吻合”或“配对 replay 改善”两条独立通道，晋升权仍属于 evaluator。
