# 8. 回滚：换回手动上传的证书

如果自动化出现问题（例如 RAM 角色被收回、CDN 侧证书槽位被别的流程覆盖）：

1. 在 Actions 里禁用 `Renew CDN certificates`（Disable workflow），停止自动续期。
2. 在 CDN 控制台为受影响域名的「HTTPS 证书」手动上传一张证书（购买的付费证书，或在仓库外
   用任意 ACME 客户端签发的证书）。自动化之前的证书条目仍在 CDN 证书列表里，也可重新选用。
3. 在这份文档里记录哪些域名处于手动模式、为什么、以及计划何时恢复。
4. 恢复自动化：修好角色或策略，重新启用工作流，手动触发一次并勾选 `force`。

不存在需要撤销的长期凭据；怀疑信任策略被滥用时，删除或收紧 RAM 角色的信任策略即可。
