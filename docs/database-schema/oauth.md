# Authorization codes and consents

What Login with CoForge's [authorization endpoint](../authorization-server/authorization-endpoint.md)
stores. Migration `20261020180000_oauth_authorization`; models in
`apps/web/prisma/models/oauth.prisma`. Every foreign key cascades, so deleting an app, a User or a
Workspace removes its codes and consents.

`oauth_authorization_codes` — one row per issued authorization code:

| Column | Type | Notes |
| --- | --- | --- |
| `id` | UUID | UUIDv7 primary key, generated by the Prisma client. |
| `codeHash` | TEXT | Unique. SHA-256 (hex) of the code; the code itself is never stored. |
| `appId` | UUID | The app (`apps`) the code was issued to. |
| `userId` | UUID | The person who authorized it. |
| `workspaceId` | UUID | The Workspace they authorized the app in. |
| `redirectUri` | TEXT | The request's redirect URI, which the token request must repeat. |
| `codeChallenge` | TEXT | The S256 PKCE challenge. |
| `nonce` | TEXT | The request's nonce, for the ID token; null without one. |
| `scopes` | TEXT[] | The scopes granted. |
| `authTime` | TIMESTAMP(3) | When the person last signed in (`auth_time`). |
| `expiresAt` | TIMESTAMP(3) | Ten minutes after issue. |
| `consumedAt` | TIMESTAMP(3) | When the code was redeemed; null until then. |
| `replayedAt` | TIMESTAMP(3) | When a redeemed code was presented again. |
| `createdAt` | TIMESTAMP(3) | |

`user_app_consents` — a person's remembered consent to an app in one Workspace: `id` (UUIDv7),
`userId`, `appId`, `workspaceId`, `scopes` TEXT[] (everything granted so far), `createdAt`,
`updatedAt`, and `revokedAt` (a revoked consent covers nothing; approving again clears it).
Unique (`userId`, `appId`, `workspaceId`).
