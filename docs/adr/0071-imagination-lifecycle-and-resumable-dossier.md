# 想象分支按证据基础失效变质，再诊断以可恢复 dossier 承载，稳定假设按门槛获得 replay 投资

想象分支基于部分相似 context 推导，会随新证据到来而过期，但纯时钟 TTL 会冤枉无新证据的成熟假设、放过已被反证推翻的新假设。决定：每条想象分支保存 evidence_basis_manifest（所用 AO/DAG refs、簇成员/边 revisions、检索与诊断快照、预测契约、已知验证结果），变质仅由 manifest 覆盖范围的事件触发（新同簇真实轨迹、簇成员/边变更、预测误差越阈、证据 redaction/ACL 变化）；状态 fresh 1.0 / needs_revalidation 0.5 / invalidated 0.0，有效置信度 = 校准置信度 × 新鲜度，一切调整以 superseding revision 审计化、旧分支保留。

增量再诊断**不持久化活 agent**（会带入不可审计的隐式记忆、过期权限、不可重放的推理状态），持久化受 ACL 保护的 diagnosis dossier（anchor、最终 context、检索与判定、簇连接、各想象分支及证据基础、未决问题、等待条件、预算与版本）；四类证据事件触发新的一次性 run，重新过来源 ACL，增量预算 ≤4 候选 / 1 path / ≤首诊 50%，优先异模型续诊（同版本须标 same-model-continuation），判定翻转必须记模型/policy 差异并形成新 revision——防自证回声。"稳定的 imagination 才值得 replay"落实为六门槛资格（校准且有效置信度 ≥0.70、fresh、簇内 ≥3 条真实证据来自 ≥2 独立 session、近 3 次证据事件未翻转结论、双样本通过或降权、本次过 ACL/七步/路径限制）：稳定想象只决定既有合规 replay 候选的投资排序，不能自带新 skill 或绕过真实效用门槛。
