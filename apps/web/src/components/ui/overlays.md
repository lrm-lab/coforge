# `src/components/ui/` — popovers and notices

The popover and notice primitives among the [deviations from official components](README.md);
the rules there apply to them too. Dialogs are in [`dialogs.md`](dialogs.md).

| File                             | Why it exists                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `emoji-picker.tsx`               | Untitled has no emoji picker; this one is the third-party `emoji-picker-react` (v5), loaded as a true dynamic import (library + the current locale's dataset land only the first time a caller opens it) and themed to the app: its epr CSS variables are pinned to the app's tokens under `[data-epr-host]` (styles.css), and light/dark follows the root `dark-mode` class. The call site composes it with the official `Button` + React Aria `DialogTrigger`/`Popover`/`Dialog`, which keep trigger, focus and dismissal semantics. Used by `features/conversations/chat-section-emoji-picker.tsx`.                                                                                                                                                                                    |
| `toast.tsx`                      | Untitled ships no toast. The one toast host and `useAppToast` (status, action, undoable, progress); one toast at a time; a new one waits behind a toast with an action and replaces one without; an error, or an Undo over an Undo, replaces at once.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `toast-model.ts`                 | The toast store and countdown, without React, so they are tested on their own.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `toast-view.tsx`                 | The toast itself: icon tile, one line, its action and close, motion with `motion`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `notice-card.tsx`                | Untitled ships no notification card. System notices only (new version, background jobs): one card with a pager.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `hover-popover.tsx`              | Wraps React Aria `PreviewTrigger` (standalone) and exports `HoverCardGroup` for velocity-gated in-place card swaps: `700ms` open delay, `300ms` leave grace, full-width invisible gap bridge, `60ms` slow-pointer swap (`0.1px/ms` over `90ms`), `200ms` fade+4px drop enter and `120ms` fade exit (`prefers-reduced-motion` fades only). Metadata in `hover-popover.meta.ts`. Used by `features/agents/agent-hover-card.tsx`, `features/conversations/person-hover-card.tsx`, and `features/tasks/task-chip.tsx`.                                                                                                                                                                                                                                                                        |
| `tooltip-group.tsx`              | Shared Label group coordinator over `base/tooltip/tooltip.tsx` and `lib/hover-intent.ts`: `500ms` initial wait, instant zero-flicker in-place switching across sibling triggers and gaps inside toolbars/charts/grids, immediate hide on group leave with `400ms` cooldown, press-to-suppress until leave, and `140ms` fade-in / `60ms` fade-out. Metadata in `base/tooltip/tooltip.meta.ts`.                                                                                                                                                                                                                                                                                                                                                                                             |
| `component-meta.ts`              | Machine-readable `ComponentMeta` schema (`category`, `whenToUse`, `whenNotToUse`, `timing`, `motion`, `accessibility`, `limits`) paired with co-located `*.meta.ts` specs across hover overlays, dialogs, feedback, loading, empty states, and motion primitives, validated by `component-meta.test.ts` and enforced by `apps/web/scripts/oxlint-plugin.js`.                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `alert.tsx`                      | Untitled UI React's Alerts are PRO-only (`npx untitledui@latest add alerts` asks for PRO access). An inline alert — featured icon, title, description, actions, optional close — composed from the official `FeaturedIcon`, `ButtonUtility` and `@untitledui/icons` with semantic tokens; its props (`color` default/gray/brand/error/warning/success, `title`, `description`, `icon`, `actions`, `onClose`/`dismissLabel`) follow Untitled's documented Alert so it can be swapped for the official one. Error and warning are `role="alert"`, the rest `role="status"`; under 28rem of its own width the actions drop under the text. Used by `features/computers/computer-upgrade-slot.tsx` and `features/agents/profile-panel/agent-migration-section.tsx` (the move-refusal notice). |
| `cascade-menu-context.tsx`       | React contexts and hooks shared between `Dropdown` and `cascade-menu-controller.tsx`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `cascade-menu-controller.tsx`    | Steady cascading submenu state engine for `Dropdown` (`base/dropdown/dropdown.tsx`): safe-zone triangle protection (`lib/cascade-menu-safe-zone.ts`), `250ms` hover open / `300ms` submenu-only leave grace (click-opened root menus never auto-close on leave), and `openOnHover={false}` for click-opened choice or typing submenus. Metadata in `base/dropdown/dropdown-submenu.meta.ts`.                                                                                                                                                                                                                                                                                                                                                                                              |
| `cascade-folder-icon.tsx`        | Animated closed-to-open folder glyph (`460ms`, `cubic-bezier(0.22, 1, 0.36, 1)`) for `Dropdown` folder rows whose submenu is open.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `cascade-menu-debug-overlay.tsx` | Optional debug overlay (`debugSafeZone` on `Dropdown.Root` / `CascadeMenu`, off by default) that draws the active safe-zone triangle and running timer.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `cascade-menu.tsx`               | Tree-driven cascading menu wrapper over `Dropdown` (`anchor` + recursive `items` tree with `label`, `icon`, `href`, `children`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
