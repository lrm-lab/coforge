# `src/components/ui/` — deviations from official components

Everything else in the app uses Untitled UI's official components unmodified
(`src/components/base/`, `src/components/application/`, installed via
`npx untitledui@latest add <name>`). The files in this directory are the only
hand-written UI primitives, kept here because Untitled has no equivalent for
them. Each one composes React Aria and/or official Untitled components at the
call site — none of them fork or copy an official component's source. See
`docs/design/official-components.md` §7.

| File                        | Why it exists                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `empty.tsx`                 | Untitled's `EmptyState` (`application/empty-state`) is a full-page block with its own backdrop and illustrations; in-page and in-panel empty states need this smaller set. Restyled with Untitled's semantic tokens.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `skeleton.tsx`              | Untitled has no generic loading-skeleton primitive.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `emoji-picker.tsx`          | Untitled has no emoji picker; this one is the third-party `emoji-picker-react` (v5), loaded as a true dynamic import (library + the current locale's dataset land only the first time a caller opens it) and themed to the app: its epr CSS variables are pinned to the app's tokens under `[data-epr-host]` (styles.css), and light/dark follows the root `dark-mode` class. The call site composes it with the official `Button` + React Aria `DialogTrigger`/`Popover`/`Dialog`, which keep trigger, focus and dismissal semantics. Used by `features/conversations/chat-section-emoji-picker.tsx`.                                                                                                                                                                                                                                                                                                                                                                                             |
| `toast.tsx`                 | Thin wrapper around `sonner` (`Toaster`/`toast`), which Untitled doesn't ship a component for. Styled with Untitled tokens via `sonner`'s `--normal-*` CSS variables.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `relative-time.tsx`         | CoForge-specific "6h ago" formatting + live re-render, built on the official `Tooltip`/`TooltipTrigger` (`#src/components/base/tooltip/tooltip`) for the exact-timestamp tooltip. Also exports `ClockTime`, the same hydration-safe/tooltip wiring showing a fixed `HH:MM:SS` instead, used by the Activity timeline's clock column.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `input-otp.tsx`             | Thin wrapper around the `input-otp` library (which Untitled doesn't wrap), restyled with Untitled tokens.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `hover-popover.tsx`         | Untitled has no hover-triggered popover, so this wraps React Aria's own `PreviewTrigger` — the official component for it: a non-modal popover on hover, focus or long press whose content may be interactive. The wrapper fixes CoForge's open delay, placement and Untitled token styling; `PreviewTrigger` owns the delays, the trigger-to-popover safe area, keyboard focus and Escape, long press on touch, and the ARIA wiring. It binds no press, so a trigger keeps its own `onPress`; that press also closes the peek, and content that navigates closes it with `useClosePreview` (both through React Aria's `OverlayTriggerStateContext`). Content goes straight into `Popover` as React Aria's example shows — a `Dialog` wrapper takes focus and breaks the peek's dismissal on touch. Used by `features/computers/runtime-usage.tsx`, `features/agents/agent-hover-card.tsx`, `features/agents/profile-panel/agent-profile-tab.tsx`, and `features/integrations/github-settings.tsx`. |
| `status-dot.tsx`            | The one live-status dot for Agents and Computers (Activity log rows use their own outlined marker). Untitled's `AvatarOnlineIndicator` only knows online/offline and is glued to `Avatar`; CoForge also needs working/thinking/error tones with a pulse, on tiles and inline status lines. Used by `features/agents/**` and `features/computers/computer-tile.tsx`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `unread-marker.tsx`         | The one unread count badge and unread dot (brand violet). Untitled's `Badge` is a labelled pill, not a count or a bare marker; the sidebar, conversation rows, thread summary and records list all use these two.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `reorderable-tab-strip.tsx` | Untitled UI has no reorderable tab strip and React Aria drag-and-drop only reorders collection components (ListBox/GridList). Renders the official horizontal `underline` `Tabs` list and moves its tabs with dnd-kit Sortable, the drag library the Task board already uses; capture-phase listeners start the drag because the tab stops its press events from bubbling, and each tab selects from its own `onPress` so a drag never switches views. Used by `features/tasks/conversation-task-tabs.tsx` and `features/agents/profile-panel/agent-profile-tabs.tsx`.                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `alert.tsx`                 | Untitled UI React's Alerts are PRO-only (`npx untitledui@latest add alerts` asks for PRO access). An inline alert — featured icon, title, description, actions, optional close — composed from the official `FeaturedIcon`, `ButtonUtility` and `@untitledui/icons` with semantic tokens; its props (`color` default/gray/brand/error/warning/success, `title`, `description`, `icon`, `actions`, `onClose`/`dismissLabel`) follow Untitled's documented Alert so it can be swapped for the official one. Error and warning are `role="alert"`, the rest `role="status"`; under 28rem of its own width the actions drop under the text. Used by `features/computers/computer-upgrade-slot.tsx` and `features/agents/profile-panel/agent-migration-section.tsx` (the move-refusal notice).                                                                                                                                                                                                          |
| `progress-steps.tsx`        | Untitled UI React's Progress steps are PRO-only (`npx untitledui@latest add progress-steps` asks for PRO access). A vertical `<ol>` of steps marked complete (check), current (a still dot, `aria-current="step"`; nothing animates) or incomplete (empty ring), composed from `@untitledui/icons` with semantic tokens. Used by `features/computers/computer-upgrade-slot.tsx`; an approved exception to the "more than one place" rule below, since the official component is PRO-only and other multi-step flows are expected to use it.                                                                                                                                                                                                                                                                                                                                                                                                                                                        |

Nothing outside this list should exist as a non-official component. If a page
needs something Untitled doesn't provide, compose it inline at the call site
from React Aria / official pieces first; only promote it to a new file here
if it's reused in more than one place, and add a row to this table explaining
why the official library has no equivalent.

## `src/components/layout/sidebar/` — the one sanctioned copy-and-adapt exception

`application/app-navigation/sidebar-navigation/sidebar-simple.tsx` and
`sidebar-slim.tsx` are official but are demo templates, not parameterized
components: they hardcode Untitled's own logo, a search box, and a fake
"Olivia Rhye" account card, and have no props for CoForge's actual
requirements (brand logo, no search, real account menu, resizable width).
They are copied into `src/components/layout/sidebar/` and adapted there —
once copied, they're CoForge's own code, no longer bound by "official source
unmodified". Everything they call into stays untouched: `app-navigation/
base-components/**` (`NavItemBase`, `NavButton`, `NavList`,
`MobileNavigationHeader`, `NavAccountCard`) and `components/base/**`.

## Lint config

`.oxlintrc.json` / `scripts/oxlint-plugin.js` may only be changed to exempt an
**unmodified official file** under `src/components/base/**` or
`src/components/application/**` from a `coforge/no-native-*` rule (each
override names the specific file, with the reason in the commit message).
Product code — this directory, `src/features/**`, `src/components/layout/**`,
routes, tests — is never exempted; a lint hit there means fix the code (see
`relative-time.tsx`'s `aria-label` fallback for an example), not loosen the
rule. No `oxlint-disable`, `@ts-ignore`, or `@ts-expect-error` comments
anywhere in the codebase.
