# `src/components/ui/` — loading and empty states

The loading and empty-state primitives among the [deviations from official components](README.md);
the rules there apply to them too. Dialogs are in [`dialogs.md`](dialogs.md), popovers and notices
in [`overlays.md`](overlays.md).

| File                   | Why it exists                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `empty.tsx`            | Single empty-state component (`EmptyState`, `RetryButton`, plus legacy `Empty*` wrappers) with `page`, `card`, `row`, and `menu` sizes, enter/exit motion, and polite live-region announcements for zero-result searches. Replaces one-off markup and Untitled's full-page `EmptyState`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `empty-icon.tsx`       | Two-tone empty-state icon wrapper (`EmptyIcon`) backed by `kubai-icons/duotone` (`48px` page / `22px` in `40×40` card tile), reading CoForge's quiet accent tokens (`--color-empty-accent`, `--color-empty-icon-body`) and playing hover motion only while hovered.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `empty-wireframes.tsx` | Self-contained inline SVG screen wireframes (`120×90` page, `80×60` no-results) styled purely with CoForge semantic CSS tokens so they follow light and dark mode automatically.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `skeleton.tsx`         | Untitled has no generic loading-skeleton primitive.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `loading.ts`           | The delayed loading-indicator policy (`useLoadingVisible`). Untitled's `Button` renders its own spinner the instant `isLoading` turns on, so a control that finishes in under a second flashes one — NN/g calls that "display inertia": too fast to follow, and it makes a fast interface read as unreliable. The policy holds the indicator for `SHOW_DELAY_MS` (150) and keeps it `MIN_VISIBLE_MS` (400) once shown, so a quick action shows nothing at all and an indicator that does appear cannot blink out a frame later. The built `Button` uses it, keeping the label visible until the indicator is genuinely on screen; the control still looks busy immediately, because the delay applies only to the indicator. Shorter than the router's `PENDING_DELAY_MS`/`PENDING_MIN_MS` (`lib/pending-policy.ts`, 300ms): a page fallback may hold that long because the whole view is changing, a control that has already changed its own look may not. |
| `spinner.tsx`          | Untitled's official `LoadingIndicator` (`application/loading-indicator`) starts at 32px and wraps the svg in a column with an optional label, so it cannot sit inline or inside a button (16–20px). Every in-progress indicator, the built `Button` included, renders this bare arc; callers pass only a size class.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
