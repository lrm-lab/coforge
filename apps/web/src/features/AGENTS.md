# Features modules

- `features/pi-chat/` — independent cloud Pi conversations, session navigation, transcript presentation, complete tool detail and the working-directory file sidebar.

The module map of `src/features/`, split out of [`apps/web/AGENTS.md`](../../AGENTS.md#module-map). Each line names a directory under `src/` and its single responsibility. Update it before adding or reorganizing a module.

- `features/agents/` — Members page, Agent creation, profile panel (its Apps tab included), control buttons, and Agent status and Activity display.
- `features/app-authorization/` — Login with CoForge's page at `/oidc/auth`: the consent an app asks for, the Workspace picker, the refusals, its Continue/Cancel server function, the page's headers, and the GET (sealed query) and POST (form) adapters before the router.
- `features/apps/` — Settings → Applications (the Installed and My apps lists, the read-only app detail every role opens from an Installed card (`app-detail.tsx`; it and the Marketplace detail share `app-dialog-parts.tsx`), the register/edit editor with its logo upload, App permissions section (behind `app-data-permissions`), Installation setup section and status (behind `app-installation-setup`), Agent access section (`agent-access-field.tsx`: All or Selected Agents, also in the app detail) and danger zone, a new secret shown once; `AppLogo` everywhere an app is shown) and the client-safe rules for an app's input, for the data an app may read (`app-permissions.ts`) and for an Agent's grant of an app (`agent-app-access.ts`), and an installation's Agent access mode (`agent-access-scope.ts`). The editor's Bot section (`app-editor-bot.tsx`) and the installation's Enable bot / Disable bot (`app-bot-grant.tsx`) are behind `app-bot` (functions in `app-bots.functions.ts`; the bot's profile body is `features/agents/profile-panel/app-bot-profile.tsx`). It also holds the App notifications section of the editor (`app-editor-notifications.tsx`, behind `app-notifications`: the webhook switch, endpoint, secret rotation and the events checklist), the event catalog and effective-event rule (`app-notification-events.ts`), and the webhook delivery status shown in the editor and the app detail. Marketplace review (behind `app-marketplace`): the editor's Distribution section and the Danger zone's offline request, the status badge, and the operators' review page (`app-review-page.tsx`, at `/w/<slug>/app-review`) with its functions (`app-publishing.functions.ts`). The Marketplace tab of Settings → Applications (`marketplace-panel.tsx`, `marketplace-listing.tsx`, the install detail `marketplace-app-detail.tsx`; functions in `app-marketplace.functions.ts`) and the uninstall row of an installed Marketplace app's detail (`app-uninstall.tsx`). Private sharing (behind `app-marketplace`): the editor's share link card (`app-share-link-card.tsx`, functions in `app-share-links.functions.ts`) and the page a share link opens, `/apps/share/<token>` (`shared-app-page.tsx`, functions in `shared-app.functions.ts`); the Marketplace detail and that page draw the same fields (`marketplace-app-fields.tsx`).
- `features/auth/` — the sign-in page (`/login`: the code tab and the password tab, each a form, and the GitHub button when configured), the password reset page (`/login/reset-password`: a code and a new password; what it leaves the sign-in page is `password-updated`), its server functions (`signInWithEmailPassword`, `requestSignInCode`, `signInWithCode`, `getSignInMethods`, `requestPasswordResetCode`, `resetPassword`), what a code is sent to and what a code looks like (`code-destination`, shared with the server), the split shell of the pages before
  sign-in, `returnTo` handling, signing out (`signOut`), the first-sign-in name step (`/welcome`), and the auth middleware for server functions.
- `features/avatars/` — how a face is drawn, for people and Agents alike: the sticker (`AvatarSticker`, `StickerPicture`), `IdentityAvatar` (a sticker picture as a sticker, an uploaded photo on the base `Avatar`; the initial and its tone from `name`; a missing picture the default cartoon person of a `userId`), the deleted-identity greying, and the radio tile of the avatar pickers (`AvatarChoice`). A lower layer: `agents/`, `conversations/` and `profiles/` import it and it imports none of them, except the import-free `agents/mascot-contract.ts`. The cartoon people's pictures and the default one an id chooses are `src/lib/person-picture.ts`, which the server reads too.
- `features/cache-persistence/` — the browser's copy of the Query cache in IndexedDB that Chat opens from (what is kept, per person, removed at sign-out).
- `features/computers/` — Computer list/detail, setup, and Runtime Usage.
- `features/conversations/` — channels, direct messages, threads, composer, message rendering, action cards, saved messages, and the sidebar lists.
- `features/device-auth/` — device-code verification page.
- `features/errors/` — page-level load-error view and the router's 404 page.
- `features/files/` — what a file is, from its name and media type: extension, size text, kind, preview kind and language, type label, and the icon it is drawn with (`FileTypeIcon`).
- `features/inbox/` — the Activity page: conversations and threads not yet marked Done, the viewer's pinned conversations above them, and the conversation a row opens beside the list (a thread's alone; full-screen below `lg`).
- `features/install/` — Computer install command text.
- `features/integrations/` — Settings → Integrations GitHub view and functions.
- `features/landing/` — the public homepage.
- `features/notifications/` — browser push lifecycle and in-page notifications.
- `features/onboarding/` — the "Finish setting up" checklist card in the Workspace sidebar: its server function, query, steps' actions, and the dismissal read from the server; the full-page "Connect GitHub" step after a Workspace is created (`/w/<slug>/connect-github`, `github-step.ts` decides skip or ask).
- `features/panel-tabs/` — each member's saved panel tab order.
- `features/profiles/` — current-user profile read and update, the one rule for a person's name (`person-name.ts`), and the avatar presets a person can choose (`avatar-presets.ts`, the four cartoon people of `src/lib/person-picture.ts`).
- `features/projects/` — Projects directory, project detail, file browser, and project settings page.
- `features/realtime/` — the one browser Centrifuge connection, and its status as the page shows it (`connection-status.ts`).
- `features/records/` — Workspace Records (see the last section).
- `features/settings/` — preference pages and device-local preferences, and what the request says
  about the browser for the server render (phone or desktop).
- `features/search/` — the Workspace search page (`search`): filters, matching channels, Agents and Computers, message results with their preview, and the browser-local search history and frequently used places.
- `features/tasks/` — Task board, list, overview, and message task actions.
- `features/workspaces/` — Workspace switcher and creation (the switcher dialog and the page a signed-in person in no Workspace lands on, `/workspaces/new`), the Workspace a page URL names (`/w/<slug>`) and the one each QueryClient last showed, member directory reads, member presence (`presence:workspace:<workspace_id>`), join links and the invite-link page (`/join/<token>`), human roles, the Settings → Workspace profile Danger zone (leave, or delete for its owner), leaving a page whose Workspace was deleted (`workspace.deleted.v1`), and the last page `/` returns to.
